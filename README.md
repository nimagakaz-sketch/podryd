# 🚜 Telegram-бот и B2B веб-парсер подрядчиков по благоустройству

Telegram-бот на **Python** (**aiogram 3.x** + **PostgreSQL/SQLite** + **openpyxl** + **BeautifulSoup4**) для автоматического сбора, дедупликации и многолистовой выгрузки базы B2B-подрядчиков по благоустройству (детские площадки, заборы/ограждения, парки, детские сады, дворы, МАФы).

---

## 🌟 Ключевой функционал

1. **Широкий сбор без отсева (`web_parser.py`)**:
   - Автоматический сбор компаний из поисковой выдачи и отраслевых каталогов по целевым регионам РФ.
   - Извлечение всех телефонов РФ, доменов, названий компаний и описаний.
   - Автоматическое тегирование по направлениям:
     - 🎠 `Детские площадки`
     - 🛡️ `Заборы и ограждения`
     - 🌳 `Парки и скверы`
     - 🏫 `Детсады и школы`
     - 🏢 `Дворы и ЖК`
     - 🛋️ `МАФы`
   - Аккуратная дедупликация: при повторном нахождении домена или телефона данные обогащаются (новые телефоны, объединенные теги), не создавая дублей.

2. **Умная выгрузка в Excel по 6 листам (`excel_export.py`)**:
   - 📑 **`Все данные`** — полный реестр всех записей базы.
   - 📞 **`С телефоном`** — горячая база контактов для холодного обзвона менеджерами.
   - 🌐 **`С сайтом`** — компании с сайтами/доменами.
   - 🎠 **`Площадки и парки`** — компании с тегами детских городков, парков и школ.
   - 🛡️ **`Заборы и МАФ`** — подрядчики по ограждениям, скамейкам и урнам.
   - 📋 **`Анкета бота`** — прямые входящие заявки от подрядчиков из Telegram.
   - В каждой строке: *ID, Источник, Направления/Теги, Регион, Телефон, Сайт, Компания/Название, Фрагмент, Telegram Username, Telegram ID, Дата и время*.

3. **Telegram Mini App (CRM онлайн) & Web API (`webapp/`, `webapp_server.py`)**:
   - Полноценная B2B CRM в темной графитовой теме (`#0b0d14`, `#121622`) с акцентами (`#7c3aed`).
   - Сводные карточки метрик: Всего в базе, С номерами телефонов, С сайтами, В работе / Сделки.
   - Живой поиск (по названию, телефону, сайту, региону, заметкам) и фильтрация по регионам, статусам, контактам.
   - Управление подрядчиками: звонок в один клик, копирование номера с тактильным откликом Telegram, мгновенная смена статуса (`new`, `price_sent`, `called`, `offer_sent`, `deal`, `rejected`) без перезагрузки страницы через AJAX, редактирование заметок.
   - Интеграция с Telegram WebApp: валидация подписи `initData` по HMAC-SHA256, поддержка авторизации администраторов из `ADMIN_IDS`.
   - Вкладка каталога МАФ и спортивного оборудования с оптовыми ценами и техническими характеристиками.
   - Вкладка аналитики воронки с прогресс-барами по статусам лидов.

4. **Гибридная база данных (`database.py`)**:
   - **PostgreSQL** (через `asyncpg`): подключается автоматически при наличии `DATABASE_URL` (на Render, Supabase, Neon).
   - **SQLite** (через `aiosqlite`): локальный fallback для разработки при отсутствии `DATABASE_URL`.
   - Безопасные миграции: автоматическое добавление колонок `status` и `notes` в существующие таблицы без потери данных.

5. **FSM-анкета и выдача каталога (`handlers/user.py`)**:
   - Пошаговый сбор данных подрядчика (Регион → Сайт → Телефон через Reply-кнопку `request_contact` или текстом).
   - Автоматическая отправка PDF-прайса с характеристиками ([`assets/price_catalog.pdf`](assets/price_catalog.pdf)).
   - Мгновенная отправка карточки лида администраторам в ЛС.

### Шаг 2. Настройка и деплой на Render (Бесплатный Web Service)

Бот поддерживает работу на бесплатном тарифе Render **Web Service (Free)** со встроенным HTTP health-check сервером (автоматически привязывается к `$PORT`, что исключает конфликты контейнеров и таймауты).

#### Вариант A. Автоматический деплой через Blueprints (Рекомендуется):
1. Зайдите в [Render Dashboard](https://dashboard.render.com/).
2. Нажмите **New +** → **Blueprint**.
3. Выберите ваш подключенный репозиторий `podryd-telegram-bot`.
4. Render автоматически прочитает файл `render.yaml` и настроит бесплатный Web Service.
5. В окне переменных окружения заполните обязательные секреты:
   - `BOT_TOKEN`: ваш токен от `@BotFather`
   - `ADMIN_IDS`: ваш Telegram ID (например, `374188835`)
   - `SERPER_API_KEY`: ваш бесплатный API-ключ от [serper.dev](https://serper.dev)
   - `DATABASE_URL`: (опционально) строка подключения к PostgreSQL.
6. Нажмите **Apply**.

---

#### Вариант B. Ручное создание сервиса (Web Service - Free):
1. В [Render Dashboard](https://dashboard.render.com/) нажмите **New +** → **Web Service**.
2. Подключите ваш GitHub-репозиторий `podryd-telegram-bot`.
3. Заполните параметры сервиса:
   - **Name**: `podryd-telegram-bot`
   - **Region**: `Frankfurt (EU Central)` или любой другой
   - **Branch**: `main`
   - **Runtime**: `Python 3`
   - **Build Command**:
     ```bash
     pip install -r requirements.txt
     ```
   - **Start Command**:
     ```bash
     python bot.py
     ```
   - **Instance Type**: `Free` (бесплатно)

4. Перейдите во вкладку **Environment Variables** и добавьте переменные:
   | Ключ | Значение | Описание |
   |---|---|---|
   | `BOT_TOKEN` | `9188680577:...` | Токен бота от @BotFather |
   | `ADMIN_IDS` | `374188835` | Ваш Telegram ID |
   | `WEBAPP_URL` | `https://podryd.onrender.com` | URL развернутого Web App для открытия Mini App в Telegram |
   | `DATABASE_URL` | `postgresql://...` | *(Опционально)* Render Postgres или Supabase |
   | `SERPER_API_KEY` | `ключ_от_serper` | **(Рекомендуется для Render)** Ключ [Serper.dev](https://serper.dev) для поиска Google без блокировок дата-центров (2,500 бесплатных поисков) |
   | `PARSER_CONCURRENCY` | `8` | Количество параллельных потоков обхода сайтов |
   | `PARSER_TIMEOUT` | `10` | Таймаут загрузки одного сайта в сек. |
   | `SEARCH_QUERIES` | `благоустройство детские площадки,установка детских городков маф,производство заборов ограждений` | Поисковые запросы |
   | `TARGET_REGIONS` | `Москва и МО,Санкт-Петербург,Краснодарский край,Екатеринбург` | Целевые регионы |

5. Нажмите **Create Web Service**. Render склонирует код, установит зависимости, запустит бота и откроет порт для Mini App.

### Шаг 3. Проверка работы

1. **Команда `/start`**:
   - Откройте бота в Telegram и отправьте `/start`.
   - Проверьте приветствие и оффер по детским площадкам, МАФам и ограждениям.
   - Нажмите **«📋 Оставить заявку / Получить прайс»** и пройдите шаги анкеты:
     - Шаг 1: Город/регион
     - Шаг 2: Сайт или кнопка «Нет сайта»
     - Шаг 3: Телефон (кнопкой или текстом)
   - Убедитесь, что бот прислал вам PDF-файл с прайс-листом и характеристиками, а в ЛС администратора пришло уведомление о новом лиде.

2. **Команда `/admin` (Панель администратора)**:
   - Отправьте боту команду `/admin`.
   - Нажмите **«🌐 Запустить сбор»**:
     - Бот подтвердит запуск парсера в фоновом режиме.
     - Парсер не блокирует работу бота и собирает организации.
     - По завершении бот пришлет отчет: сколько организаций добавлено и обновлено.
   - Нажмите **«📊 Скачать базу в Excel»**:
     - Бот сформирует и пришлет `.xlsx` файл со всеми **6 вкладками** (`Все данные`, `С телефоном`, `С сайтом`, `Площадки и парки`, `Заборы и МАФ`, `Анкета бота`).
   - Нажмите **«📈 Статистика»**:
     - Отобразится детальный срез базы по источникам и категориям.
