# Liquid Glass для Telegram Mini Apps

Стеклянный интерфейс в стиле iOS 27 для мини-приложений Telegram: жидкая «капля» в таб-баре, стеклянные кнопки, iOS-карточки настроек.
Автор: **Volodymyr** — [@vovnx](https://t.me/vovnx) · канал [@voco_in](https://t.me/voco_in)

Всё работает в одном HTML-файле, без сборщика и зависимостей (Telegram SDK и lottie-web подключаются по `<script>`).

## Что в папке

```
liquid-glass-kit/
├── README.md              ← этот файл (внизу — промпт для ИИ)
├── demo/
│   └── index.html         ← полное демо: чаты, контакты, настройки, поиск, меню, 5 языков
└── components/            ← по одному компоненту на файл, каждый открывается сам по себе
    ├── tabbar.html        ← таб-бар с жидкой каплей (физика, деформация, слияние с краем бара)
    ├── buttons.html       ← стеклянные кнопки: пилюля, квадрат, круг (тянутся и пружинят)
    └── cards.html         ← экран «Настройки»: карточки, плашка автора, теги, карусель, пасхалки
```

`demo/index.html` — эталон. Компоненты вынесены из него, поэтому формулы и числа совпадают.

## Быстрый старт

1. Открой любой файл из `components/` в Chrome — увидишь компонент на цветном фоне.
2. Чтобы запустить в Telegram, выложи папку на любой HTTPS-хостинг статики (GitHub Pages, Netlify, Vercel).
3. В @BotFather укажи адрес страницы как Web App (кнопка меню бота или `/newapp`).

Проверка в Telegram и на реальных телефонах — на тебе: я проверял только синтаксис и запуск без ошибок в тестовом окружении, ощущение физики на устройстве не смотрел.

## Как это устроено

| Слой | Что делает | Где в коде |
|---|---|---|
| Стекло | `feDisplacementMap` + блик из SVG-фильтра, фильтры строятся на лету под размер элемента | `profile`, `maps`, `filterFor`, `rebuild` |
| Матовая основа | `backdrop-filter: blur + saturate`, тонкий светящийся кантик | `.matte`, `.matte::before` |
| Капля | линза `.lens` поверх клона вкладок, двигается через CSS-переменные | `.thumb`, `.lens`, переменные `--x --tx --sx --sy --p` |
| Физика капли | пружины: положение, зажатие, «хвост», вертикальная пульсация, упор в стенки | функция `loop` |
| Слияние | край бара тянется к выступившей капле (`clip-path: path(...)` строится каждый кадр) | блок `.fil` в `loop` |
| Кнопки | «тугая» жидкая капля: тянется с сопротивлением, растёт при нажатии | `glassBtn` |

Размеры считаются в условных единицах `--u` (1u ≈ 0.46px): бар 843×190u, капля 252×165u, вкладка 273u. Всё масштабируется от одного значения.

## Куда крутить ощущение (таб-бар)

Все числа лежат в функции `loop` внутри `tabbar.html`.

| Что меняется | Параметр | Сейчас |
|---|---|---|
| Скорость переключения | `k` (жёсткость после тапа) | 230 |
| Инерция/перелёт | `c = 1.6·√k` (меньше множитель → больше перелёт, 2 → вообще без перелёта) | 1.6 |
| Высота капли в пути | `sy = 1 + .24·g + .16·press` | .24 |
| Растяжение по ширине | `st = clamp(|vel|·.055, 0, .26)` | .055 / .26 |
| «Желе» хвоста | коэффициент `jel` (`.48`) | .48 |
| Потолок ширины | `sxv = Math.min(sxv, 1.38)` | 1.38 |
| Сплющивание при приземлении | `zzv -= 2.4` | 2.4 |
| «Набухание» на старте | `zzv += 1.4` | 1.4 |
| Слияние с краем бара | включается, когда капля торчит больше 1.5u | 1.5 |
| Кнопки: под пальцем / в покое | `k, c` в `glassBtn` | 260, 24 / 150, 9 |

## Как перенести компонент в свой апп

1. Скопируй CSS, HTML и `<script>` нужного компонента из `components/`.
2. Оставь `<svg ...><defs id="defs"></defs></svg>` — туда пишутся фильтры стекла.
3. Для бара подпишись на смену вкладки: `window.onTabChange = i => { /* 0, 1, 2 */ }`.
4. Хочешь другие иконки или названия — меняй содержимое `.tab` (иконка 70u высотой, подпись под ней).
5. Размер подогнан под 3 вкладки. Для другого числа вкладок нужно менять `grid-template-columns`, ширину бара и границы в `loop` (см. промпт ниже).

## Совместимость

`backdrop-filter: url(#svg)` понимает только Chromium (Telegram Desktop, Android WebView). В Safari/WebView на iOS код автоматически оставляет обычное размытие из CSS, капля и физика работают, но без преломления на фоне. Эту часть я по коду вижу, на устройствах не проверял.

# Промпт для ИИ (скопируй целиком и приложи нужный файл)

```text
Ты — frontend-разработчик. Я даю тебе файл из набора «Liquid Glass для Telegram Mini Apps» (стеклянный UI в стиле iOS 27). Доработай его по моей задаче и верни ПОЛНЫЙ обновлённый файл.

КОНТЕКСТ
- Один самодостаточный HTML-файл: CSS + HTML + JS внутри, без сборщика и фреймворков.
- Внешние скрипты только: telegram-web-app.js и (по желанию) lottie-web с cdnjs.
- Целевая платформа: Telegram Mini Apps (WebView на телефонах и Desktop). Учитывай safe-area (переменные --tg-safe-area-inset-*, env(safe-area-inset-*)).

АРХИТЕКТУРА (не ломай)
1. Стекло = SVG-фильтр feDisplacementMap + блик. Функции surf, profile, maps, filterFor, rebuild строят фильтры под реальный размер элемента. Пересборка идёт через ResizeObserver. Без причины эти формулы не меняй.
2. Матовая основа — класс .matte (backdrop-filter + кантик ::before). Линза — .glass > .lens. Мягкое стекло для маленьких кнопок — data-soft="1".
3. Размеры задаются в единицах --u (calc(N*var(--u))): бар 843×190u, капля 252×165u, вкладка 273u. Новые элементы масштабируй так же или в px, но не смешивай без причины.
4. Капля бара управляется только CSS-переменными на #bar: --x --tx --sx --sy --p. Их каждый кадр выставляет функция loop. Не двигай каплю напрямую через left/transform в обход loop.
5. Физика — пружины в loop (положение, зажатие press, «хвост» lag, вертикальная пружина zz, упор в стенки sm()). Меняй числа точечно и объясняй, как они влияют на ощущение.
6. Слияние края бара с каплей — clip-path: path(...) на .fil, строится каждый кадр, когда капля выступает за бар больше чем на 1.5u. Не удаляй.
7. Кнопки — функция glassBtn (перетягивание с сопротивлением, пружина назад). Содержимое .gc клонируется в линзу скриптом.
8. backdrop-filter: url(#svg) работает только в Chromium. Фолбэк на обычное размытие должен остаться.

ПРАВИЛА РАБОТЫ
- Меняй минимум кода. Не переписывай то, что работает, и не переименовывай существующие классы и id.
- Если добавляешь вкладки или кнопки, обнови всё, что от этого зависит: grid-template-columns, ширину бара, границы в loop, клон вкладок в линзе, подсветку.
- Анимации — на transform/opacity/CSS-переменных, без анимации width/height и без setInterval. Только requestAnimationFrame.
- Уважай prefers-reduced-motion: при нём оставь переключение без пружинных эффектов.
- Не добавляй localStorage без необходимости и не добавляй внешние запросы кроме перечисленных выше.
- Тексты интерфейса оставь на русском, если я не просил иначе.

ФОРМАТ ОТВЕТА
1. Что изменил — 3–6 коротких пунктов.
2. Полный код файла.
3. Что проверить руками на телефоне (если есть риски по физике или стеклу).

МОЯ ЗАДАЧА
<<< опиши, что нужно сделать, например: «добавь 4-ю вкладку», «сделай светлую тему», «добавь кнопку-переключатель с каплей», «сделай меню в стиле iOS с этим стеклом» >>>
```
